# Refresh-theme-urbanrain-aus-shopify-store
Hi, I'm Hanan Ali. This repository contains custom liquid code and theme modifications I've developed for various Shopify projects, specifically using the Refresh and Dawn themes.

Currently, I am working on building and optimizing e-commerce stores like AquaFit.pk and Urbanrain.Aus, focusing on both technical development and digital marketing.

🛠 What I've Built
Custom "Follow Us" Footer Logic
One of the common issues with Shopify's text blocks is the lack of flexibility. I wrote a custom Liquid snippet for the footer that:

Detects when a text block heading is set to "Follow Us".

Automatically pulls and displays social media icons (Facebook, Instagram, WhatsApp) from the theme settings.

This removes the need for manual HTML in the subtext field and makes the store easier to manage for clients.

Theme Optimization
Applied custom CSS to ensure icons and text align perfectly on both mobile and desktop.

Modified footer.liquid to allow better branding for local Pakistani e-commerce stores.

Cleaned up redundant code in the theme files to maintain fast loading speeds.

📁 Repository Structure
Sections: Includes my modified footer.liquid file.

Snippets: Any custom liquid code used for icons or specific features.

CSS: Custom styling used to fix layout issues in the Refresh theme.
